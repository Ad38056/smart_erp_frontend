# smart_erp_frontend (React - Vite)

This workspace was scaffolded to run as a Vite + React app. It contains a minimal router and placeholder components for each existing HTML page.

Quick start

1. Install dependencies

```bash
npm install
```

2. Start dev server

```bash
npm run dev
```

Notes

-- Original static files (`*.html`, `js/`, `assets/`) remain in the workspace so you can incrementally migrate markup and logic into `src/pages` and `src/components`.
-- Project CSS has been migrated into `src/styles/` and is imported from `src/index.css`.
